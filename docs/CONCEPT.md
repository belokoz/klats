# Клац — концепция

Версия 2, принята 17 сентября 2026. Латиницей: **Klats**. Идентификатор: `io.github.belokoz.klats`.

## Что это

Клац живёт в строке меню macOS и умеет одну вещь: по `⌥⌘` переводит выделенный текст в другую раскладку. «ghbdtn» становится «привет», «руддщ» становится «hello». Бонусом, той же механикой, по `⌥⌘Z` меняет регистр выделенного.

Зачем: Punto Switcher купил Яндекс и перестал развивать, а сам Punto — комбайн. Нужно одно действие без комбайна: маленькая честная программа, которую любой может скачать, собрать и проверить.

## Принципы

1. **Одна функция, сделанная хорошо.** Смена раскладки выделенного текста. Регистр — бонус. История буфера обмена придёт отдельной версией.
2. **Ничего лишнего.** Нет автопереключения, автозамены, словарей, статистики, звуков, фоновых обновлений.
3. **Лёгкая.** Нативный Swift, без Electron, без сторонних библиотек. Цель: меньше 15 МБ памяти, ноль процессора в покое.
4. **Ничего не уходит наружу.** Сетевого кода нет вообще. Текст не сохраняется и не логируется.
5. **Ставится за минуту.** Скачал, перетащил в «Программы», один раз «Открыть всё равно», дал одно разрешение.
6. **Открытая.** Код на GitHub под MIT.

## Сценарии

- **Раскладка.** Печатаешь, видишь «ghbdtn», выделяешь, нажимаешь и отпускаешь `⌥⌘`. Текст стал «привет», системная раскладка переключилась на русскую.
- **Регистр.** «пРИВЕТ» → выделил → `⌥⌘Z` → «Привет» (режим «инвертировать») или «привет» (режим «все строчные»).
- **Первый запуск.** «Открыть всё равно» в системных настройках, затем один экран с просьбой выдать Универсальный доступ. После этого иконка в строке меню, хоткеи уже работают.

Чего не делаем: автопереключение по мере набора, автозамены, исправление без выделения (в v1), транслитерация, история буфера обмена (в v1), звуки, аналитика, автообновление в фоне.

## Как это работает

**Замена текста.** Хоткей → синтетическое `⌘C` → читаем буфер → преобразуем → кладём результат в буфер → синтетическое `⌘V` → возвращаем прежнее содержимое буфера → переключаем системную раскладку. Работает везде, где работают `⌘C` и `⌘V`. Accessibility API как замена буферу работает только в части приложений, поэтому оставлен как ускорение на потом.

**Конвертация.** Таблицы «символ ⇄ клавиша» строятся из реальных раскладок системы через `UCKeyTranslate`, а не зашиты в код: символ → клавиша в исходной раскладке → символ на той же клавише в целевой. Работает для любой пары раскладок и сам учитывает Shift. Направление определяется по тексту: считаем символы, которые есть только в одной из двух раскладок. Общие символы и незнакомые (эмодзи) проходят как есть. Проверено на ABC ⇄ Русская – ПК: таблицы строятся за 0,2 мс.

**Регистр.** «Инвертировать»: каждая буква меняет регистр. «Все строчные»: всё в нижний регистр.

**Горячие клавиши.** `⌥⌘` состоит из одних модификаторов, система такие не регистрирует. Клац следит за состоянием модификаторов и срабатывает при отпускании, если между нажатием и отпусканием не было ни клавиши, ни клика. На этапе дизайна предложено ловить оба хоткея одним перехватчиком `CGEventTap` (см. `DESIGN.md`, когда появится).

**Из чего сделано.** Swift 6, AppKit + SwiftUI, macOS 13+, универсальный бинарник (arm64 + x86_64), `TISSelectInputSource`, `UserDefaults`, `SMAppService`, Swift Package + скрипт сборки `.app` без Xcode, ноль зависимостей.

## Ограничения и риски

- Без Универсального доступа ничего не работает.
- Без подписи Apple: «Открыть всё равно» при установке; разрешение может слетать после обновления (выключить и включить заново).
- Ошибся или передумал: `⌘Z` отменяет замену, как обычную вставку. Тонкости срабатывания `⌥⌘` описаны в DESIGN.md.
- Терминалы, удалённые рабочие столы, игры не поддерживаются. В полях паролей Клац ничего не делает.
- Вставляется простой текст, форматирование берётся у окружения.
- Промежуточная копия помечается как временная (org.nspasteboard), чтобы её пропускали менеджеры буфера.
- Буфер возвращаем примерно через 0,2 с после `⌘V`.
- Методы ввода (японский, китайский, корейский) в пары не входят.

## Потом

**v1.1: история буфера обмена как в Windows (Win+V), хоткей `⌃V`.** 25 последних элементов (в настройках до 100); текст с форматированием, картинки, файлы из Finder, до 4 МБ на элемент; панель у текстового курсора или у мыши; клик или Return вставляет, стрелки выбирают, Esc закрывает; закрепить, удалить, очистить всё; `⇧Return` вставляет как текст; история очищается при перезапуске, закреплённые остаются; без облака, без эмодзи. Механика: опрос счётчика изменений буфера дважды в секунду; плавающая панель, не забирающая фокус; вставка через `⌘V`. В историю не попадает помеченное как секретное или временное. Перед v1.1 решить: сколько хранить, переживает ли перезапуск, что хранить.

Остальное: последнее слово без выделения (как в Punto), путь через Accessibility API без буфера, транслитерация, цикл регистра как Shift+F3 в Word, скрытие иконки, проверка новых версий по ссылке на GitHub Releases, Windows и Linux.
